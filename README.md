# N캐 · 빵친자 프로토타입

네이버 N캐(부캐) 서비스의 빵친자 루프를 휴대폰에서 직접 눌러볼 수 있는 웹 프로토타입입니다.

## 휴대폰으로 열기 (GitHub Pages)

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 **전부** 올립니다. `.nojekyll` 파일도 같이 올려야 합니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 고르고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다. 이 주소를 휴대폰에서 엽니다.
4. 앱처럼 쓰려면 홈 화면에 추가합니다.
   - iPhone: Safari 공유 버튼 → 홈 화면에 추가
   - Android: Chrome 메뉴 → 홈 화면에 추가

휴대폰에서는 화면 폭에 맞춰 꽉 차게 보입니다. PC에서 열면 가운데 폰 화면과 왼쪽 화면 목록이 함께 보입니다.

## 바로 가는 주소

주소 끝에 `#화면이름`을 붙이면 그 화면에서 시작합니다.

| 화면 | 주소 끝 |
|---|---|
| 유입 인트로 | (없음) |
| 부캐 홈 | `#home` |
| 부캐 입장 · 빵친자 | `#enter` |
| 빵친자 꾸미기 | `#deco` |
| 탐색 | `#explore` |
| 클립 상세 | `#detail` |
| 파티 구경하기 | `#partyview` |
| 빵묵자 파티 보드 | `#board` |
| 초대장 | `#invite` |
| 공동구매 팟 | `#groupbuy` |
| 공유 리스트 | `#list` |
| 밸런스 게임 | `#vs` |
| 다녀옴 확인 | `#recStamp` |

## 조작

- 왼쪽 가장자리를 오른쪽으로 쓸면 뒤로 갑니다.
- 바텀시트는 손잡이를 아래로 끌어 닫습니다.

## 파일 구성

- `index.html`: 앱 전체 화면, 스타일, 동작
- `intro.html`: 유입 인트로 원본
- `a/`: 이미지·아이콘·영상
- `fonts/`: Pretendard, 나눔스퀘어 네오

## 참고

- 실제 서버와 연결되지 않은 프로토타입입니다. 예약, 결제, 알림, 사진 업로드 등은 화면 흐름만 동작합니다.
- 일부 가게 사진은 맛집 리뷰 사이트(polle.com 등)의 사용자 사진입니다. 외부에 공개하려면 사용 허락을 받거나 직접 찍은 사진으로 바꾸세요.
